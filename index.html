AWS CI/CD Pipeline Lifecycle

Demonstrating continuous integration and continuous delivery workflow with GitHub, AWS CodeBuild, Amazon S3 static web hosting, and AWS CloudFront content delivery network.

PHASE 1

GitHub Source

Webhook listens for git push commits on main branch.

PHASE 2

AWS CodeBuild

Executes buildspec.yml, installs Node.js runtime & pre-build checks.

PHASE 3

Verification & Test

Runs scripts/build-check.js, stamps metadata, validates syntax.

PHASE 4

S3 & CloudFront

Syncs artifacts to S3 bucket & creates CloudFront cache invalidation.

AWS CodeBuild & Project Requirements

This repository includes all required configuration files to run AWS CodeBuild, Amazon S3 static website hosting, and AWS CodePipeline seamlessly.

buildspec.yml

The official AWS CodeBuild specification declaring runtime phases (install, pre_build, build, post_build) and output artifacts.

location: /buildspec.yml

buildspec-deploy.yml

Automated direct S3 sync (`aws s3 sync`) & CloudFront cache invalidation script for one-click AWS deployments.

location: /buildspec-deploy.yml

scripts/build-check.js

Automated verification script executing in CodeBuild `pre_build` to validate all files, check JavaScript syntax, and generate build-info metadata.

location: /scripts/build-check.js

DEPLOYMENT.md

Step-by-step documentation detailing how to configure AWS CodeBuild, IAM Service Roles, S3 Bucket Static Hosting, and GitHub webhooks.

location: /DEPLOYMENT.md

⚡ AWS CodeBuild Quick Setup Guide

To connect this repository to AWS CodeBuild and deploy your static website:

  1. Create an S3 Bucket with Static Website Hosting enabled.
  2. In AWS CodeBuild, create a new Build Project and select GitHub as the source provider with repo https://github.com/AnujThorat/myfirst-cicd-project.git.
  3. Choose Environment: Managed Image, Operating System: Amazon Linux / Ubuntu, Runtime: Standard (Image 7.0+).
  4. Under Buildspec, select Use a buildspec file (it will automatically detect buildspec.yml).
  5. Under Artifacts, select Amazon S3 and select your destination bucket.
  6. Click Start Build!
